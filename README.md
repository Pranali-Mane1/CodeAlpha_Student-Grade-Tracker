# Student Grade Tracker Using Java

A console-based Student Grade Tracker developed using Java as part of my CodeAlpha Java Programming Internship.

## Features
- Accepts student names and marks for three subjects.
- Calculates the average marks of each student.
- Displays the highest and lowest marks for each student.
- Calculates the overall class average.
- Identifies the top-performing student and the student with the lowest average.
- Validates student names and marks.
- Supports multiple students.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Arrays
- Scanner Class
- Loops and Conditional Statements

## How to Run
1. Install the Java Development Kit (JDK).
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the terminal and run:

```bash
javac StudentGradeTracker.java
java StudentGradeTracker
```

## How It Works
The program accepts the number of students, their names, and marks in three subjects. It calculates individual averages, highest and lowest subject marks, the class average, and identifies the top and lowest-average students.
